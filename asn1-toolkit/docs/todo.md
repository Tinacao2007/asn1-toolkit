## STD-01：约束、参数化和信息对象语义

- [ ] 实现引用类型继承约束的交集和保真 IR，补 FROM、普通 WITH COMPONENTS、COMPONENTS OF、数字版本扩展组；未支持形式继续明确拒绝。
- [ ] 补匿名/内建类型实参及约束的多实例键、嵌套和递归实例化专项回归。
- [ ] 按家族核查 BigInteger、超大有界描述符和编码侧完整约束检查，不以原生整数已有检查推定全部通过。
- [ ] 核查对象/对象集运算、固定字段约束及完整表成员验证，区分控制字段选择与完整约束语义。
- [ ] 继续核对标准基线与适用勘误，保存条款、实现和接受/拒绝探针的对应关系。

验收：约束不丢失、不静默退化为无约束；两个不同实参实例的实际位宽/线路不串用；每项接受和拒绝都有真实生成测试及适用独立向量。

## STD-02：规范规则与合法替代表示

- [ ] 按 C/C++ 分开核查时间规范词法、命名位串尾零和剩余值域；C11 UTCTime/命名位串的已完成范围只保留回归，不重复实现。
- [ ] 核查模式感知 CER SET 顺序、COER/XML DEFAULT 与未知扩展策略等剩余组合。

验收：同一抽象值的基础规则合法替代与规范规则负例成对验证；条款、字节、错误状态和未知扩展边界明确。不支持的值域不通过放松规范检查伪装完成。

## STD-03：精确 REAL 模型

- [ ] 设计精确二进制/十进制 REAL 抽象值，明确与现有宿主 double 接口的转换及兼容边界。
